# نظام مخزون وحدات + CRM (نسخة بسيطة)

برنامج بايثون بسيط يشتغل من سطر الأوامر لإدارة:
- المخزون (الأصناف، الكميات، الأسعار)
- العملاء (CRM)
- طلبات البيع مع خصم الكمية تلقائياً من المخزون

## التشغيل

```bash
python3 app.py
```

سيتم إنشاء قاعدة بيانات SQLite محلياً باسم:

`crm_inventory.db`

## الوظائف المتوفرة

1. إضافة صنف للمخزون
2. عرض الأصناف
3. إضافة عميل
4. عرض العملاء
5. إنشاء طلب بيع
6. عرض الطلبات

## ملاحظات

- هذا نموذج أولي ويمكن تطويره لاحقاً إلى واجهة ويب أو تطبيق سطح مكتب.
- البيانات تحفظ محلياً على نفس الجهاز.
