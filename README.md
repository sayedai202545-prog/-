# نظام مخزون وحدات + CRM (نسخة بسيطة)

برنامج بايثون بسيط يشتغل من سطر الأوامر لإدارة:
- المخزون (الأصناف، الكميات، الأسعار)
- العملاء (CRM)
- طلبات البيع مع خصم الكمية تلقائياً من المخزون

## ازاي أشغله على الجهاز؟

### 1) تأكد إن Python متثبت

- **Windows**
  - افتح PowerShell واكتب:
    ```powershell
    py --version
    ```
  - لو ظهر رقم إصدار (مثلاً 3.11) يبقى تمام.

- **macOS / Linux**
  - افتح Terminal واكتب:
    ```bash
    python3 --version
    ```

> لو Python مش متثبت، نزّله من الموقع الرسمي: https://www.python.org/downloads/

### 2) افتح المشروع من التيرمنال

```bash
cd path/to/project
```

استبدل `path/to/project` بمكان الملفات عندك.

### 3) شغل البرنامج

- **Windows**:
  ```powershell
  py app.py
  ```
- **macOS / Linux**:
  ```bash
  python3 app.py
  ```

### 4) استخدم القائمة

هتظهرلك قائمة زي:

- 1 إضافة صنف
- 2 عرض الأصناف
- 3 إضافة عميل
- 4 عرض العملاء
- 5 إنشاء طلب بيع
- 6 عرض الطلبات
- 0 خروج

اكتب رقم العملية واضغط Enter.

## أين تُحفظ البيانات؟

أول ما البرنامج يشتغل، بينشئ ملف قاعدة بيانات محلي باسم:

`crm_inventory.db`

ده الملف اللي فيه كل البيانات (الأصناف/العملاء/الطلبات).

## ملاحظات مهمة

- لو حبيت تبدأ من الصفر، اقفل البرنامج واحذف ملف `crm_inventory.db`.
- الأفضل تسيب `app.py` و`crm_inventory.db` في نفس المجلد.
- هذا نموذج أولي ويمكن تطويره لاحقاً إلى واجهة ويب أو تطبيق سطح مكتب.
